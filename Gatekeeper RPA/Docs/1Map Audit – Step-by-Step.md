1Map Audit – Step-by-Step
0) Prereqs

You have a valid 1Map login.

You know the DR/Drop Number (e.g., DR1854443 or FT-123456).

1) Sign in

Go to https://www.1map.co.za/login
.

Enter your Email and Password → Sign in.

Make sure that Playwright has viewing access rights only

If SSO/Microsoft is used, complete that flow.

2) Open the 1Map app

In the top nav, hover “Portal”.

Click “1Map app”.

Wait for the 1Map interface to load.

3) Choose the correct workspace

Open the Active Workspace dropdown (right panel / toolbar area).

Select “Home Signups & Installations” (or Home Signup & Home Installation as labelled in your environment).

Confirm the workspace name shows as selected.

4) Search the active layer for the Drop

Click in the Active Layer Search input (the search tied to the results table, not global search).

Paste or type the Drop Number exactly (e.g., DR1854443).

Press Enter and wait for the results table/grid to populate.

🔎 Tip: If your drops sometimes include dashes (e.g., FT-123456), try both with and without the dash if no result appears.

5) Disable “Selected features”

Locate the Selected features toggle/button and turn it OFF.
This ensures the table shows all rows matching your search, not just features currently selected on the map.

6) Identify the correct row

In the results table:

Find the row where:

Drop Number equals your search, and

Status equals “Home Installation: Installed”.

If multiple rows appear, match by address/ID as needed.

⚠️ If you can’t find the right status, confirm you’re in the correct workspace and that the search field is for the active layer.

7) Open the row details

Click the row (or its open/detail icon) to open the details drawer/panel.

Inside the details:

Navigate between Attachments/Photos and Metadata/Attributes tabs (labels may vary slightly).

8) Review attachments (photos/documents)

Go to Attachments / Photos tab.

You should see a list of uploaded images (often with a preview/thumbnail).

For each image:

Preview to check content.

Use Download if you need local copies (for audit pack or ML later).

Confirm you have the full set expected for a home install (your standard is 14 items).

If 1Map doesn’t label by step, use order + content to verify:

Frontage, wall (before), outside span, entry outside, entry inside, fibre→ONT (after), patched & labelled drop, overall area, ONT barcode, UPS serial, powermeter (drop/feeder), powermeter at ONT (before activation), active broadband light, signature.
